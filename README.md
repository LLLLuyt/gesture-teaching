# 布 vs 石头 · 手势识别训练实验

小学人工智能通识课教学工具：用摄像头采集手势图片，训练一个属于同学们自己的「AI 模型」，通过两轮实验对比，感受训练数据多少对识别准确率的影响。

## 功能

- 两个标签：「布」「石头」
- 第 1 轮每类采集 4 张图片 → 同学检验识别率
- 第 2 轮增加图片数量（默认每类 20 张）→ 同一同学再检验，两轮准确率柱状图对比
- 采集与检验全程显示 21 个手部关键点骨架
- 识别率由程序真实计算（KNN 多数投票），数据不造假；同时展示平均置信度辅助教学

## 本地使用

- 双击 `启动服务器.bat`（推荐：离线可用，自动打开浏览器）
- 或直接打开 `index.html`（需电脑能联网加载模型）

## 在线使用

部署后访问 GitHub Pages 地址即可，https 环境下浏览器会自动允许摄像头权限。

## 技术说明

- MediaPipe Hands：手部 21 关键点检测（@mediapipe/hands 0.4.1675469240）
- 自写 KNN 分类器：42 维归一化关键点特征，k=3 多数投票
- 纯原生 HTML/JS/CSS，无框架、无后端；模型加载优先本地 `mediapipe/` 文件夹，失败自动回退国内 CDN
